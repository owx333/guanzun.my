01Google API 金钥

金钥只会存在你这台电脑的浏览器（localStorage），不会上传。
还没有金钥？点这里看申请步骤
  1. 打开 console.cloud.google.com，新建一个项目（或用现有的）。
  2. 左边选单进 "APIs & Services" → "Library"，搜索并启用 Places API (New)（注意不是旧版 Places API，旧版已经不开放给新项目）。
  3. 系统会要求绑定帐单帐户（需要信用卡）。这不代表马上收费 — Google 每个月给每个 SKU 免费额度：只抓名字/地址属于 Pro 级，每月 5,000 次免费；超出后大约 $32 美金/1000次。如果多勾电话、网站、评分这些字段，会跳到 Enterprise 级，大约 $35/1000次，免费额度也比较少（每月 1,000 次）。2025 年 3 月起 Google 已经取消旧版每月 $200 统一额度，改成这种按字段分级的额度，所以字段勾越多，费用可能跳更快。
  4. 到 "Credentials" 建立 API 金钥，建议限制它只能调用 Places API (New)，避免被盗用。
  5. 把金钥贴回上面的输入框，按"保存"。
